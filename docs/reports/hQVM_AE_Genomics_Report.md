# hQVM AE Genomics Program

The RNA design literature weighs candidate sequences by uniform sampling [2], thermodynamic energy, or a prior learned from biological families [7]. This program occupies a fourth seat: a formal grammar with no biological training data. Reproducible contact between grammar-trained readouts and genomic structure, under composition controls, is the measured signal.

This report records what the program measured and how each result is bounded. Program design and methodology live in the program specification. This document is the record of outcomes.

## Repository and reproducibility

This report describes genomics results from the [gyrogovernance/superintelligence](https://github.com/gyrogovernance/superintelligence) repository. The analysis code is under `src/tools/autoencoder/programs/genomics/`. The Synthesis domain evaluations are in `synthesis/`, and the Topology domain (membrane topology and fixed-peptide analyses) is in `topology/`. The shared hQVM autoencoder package, including models, kernel adapters, and production checkpoints, is under `src/tools/autoencoder/`. Entry points, data ingest, and result files are documented in that tree.

## Scientific position

The hQVM AE Genomics program combines an exact coordinate system for coding DNA with autoencoders trained on sequences generated by that system. The coordinate system represents nucleotides and codons as exact algebraic states. Adjacent codons form ordered transitions, and the kernel assigns each transition a local cost called shell. A coding sequence is a path through these states, and the kernel computes exact properties of that path. The autoencoders learn to reconstruct masked positions in grammar-generated paths and provide learned summaries of sequence order.

Coherent marks at modest effect size are the expected regime. Family-trained measures fit the biological family itself and leave most of the variance in measured function unexplained [7, 8]. Against that ceiling, a grammar-trained instrument that never saw biological training data still produces small, ordered contacts. The Gamble library sets the same scale directly: its within-peptide expression spread is small, so the mean rank correlation of 0.0196 reported below is a proportionate ordering under fixed peptide identity.

Two properties of the coordinate system shape how the results should be read. Its cost function is a path quantity, the same class of object the field's kinetic design literature reasons with when it separates folding paths, barriers, and seed accessibility from endpoint energy. The coordinate system was derived from the CGM axioms, so the shell distances used here were fixed before any gene was read. The Topology contrast is therefore an unsolicited biological consequence of that cost function. The derivation and its 301 verification checks are recorded in the genomics analysis [12].

This design separates the fixed coordinate system from learned sequence representations. The kernel is determined by the hQVM algebra, and biological catalogs enter at evaluation. That separation is what lets a grammar-derived representation be scored against real genomes, protein topology, and synonymous expression.

## Results overview

The program reports results in two domains. The Synthesis domain evaluates the frozen models on genomic catalogs. The Topology domain measures adjacent codon-pair order against membrane topology within individual *E. coli* genes, frozen-model held-out classification on the same cohort, and synonymous expression ranking in a fixed-peptide library. Each model claim below is measured as an increment over the kernel and composition controls.

The analyses escalate by holding more fixed each time. Synthesis works across whole catalogs and four organisms, with composition controls applied at comparison time. Membrane Topology holds the organism, gene, encoded protein, and host codon usage fixed and varies the annotated domain. Fixed-peptide Topology holds the peptide itself fixed, so codon order is the free variable and the learned measure is on its home ground. That final number is the smallest of the three, and the cleanest test under maximum control.

## Coordinate system and models

The hQVM kernel compiles a DNA window into a sequence of carrier states. It records exact path properties, including parity, complementarity, word signatures, and the shell cost of adjacent codon pairs. These quantities are computed from the coordinate system.

Narrow and Super are frozen model components evaluated by the program. Narrow provides a compact representation of each Topology window. Super performs masked prediction and supplies an aggregate window readout called climate. Randomly initialized models with the same architectures provide a comparison for the contribution of trained weights.

## Synthesis domain results

The Synthesis domain evaluates K4, Narrow, spectral, and Super components on *E. coli*, yeast, SARS-CoV-2, and human chromosome 22 splice flanks. K4 preserves the required group symmetry with a maximum error of `3.32e-11`. Even-depth sliding commutators are the identity on every tested window. Odd-depth commutators are non-identity in `98.23%` of *E. coli* windows and `98.06%` of yeast windows.

The distributional comparison with the uniform carrier atlas is substantial. Total-variation distances for byte marginals are `0.1815` in *E. coli*, `0.1939` in yeast, and `0.2463` in SARS-CoV-2. The corresponding six-bit-state distances are `0.1308`, `0.1352`, and `0.1741`. Living catalogs occupy distinct, measurable regions of the carrier state space relative to the uniform grammar atlas.

The order-memory test constructs sequence pairs with the same algebraic signature and byte multiset while changing only path order. Trained-minus-random cosine-distance margins are `+0.1931` on chromosome 22, `+0.2045` in *E. coli*, `+0.2250` in yeast, and `+0.2271` in SARS-CoV-2. Trained Super retains information about order beyond both the fixed carrier quantities and the untrained architecture.

Against GC-matched shuffles, Super climate reaches AUC `0.8408` in *E. coli* and `0.7113` in yeast. The trained-minus-random gaps are `+0.2124` and `+0.1052`. The kernel's own mean-shell statistic reaches pooled AUC `0.9190` in *E. coli* and `0.8336` in yeast on the same comparison, above the Super climate head. That ordering is a theory result: the grammar already carries the discrimination, and the learned head contributes its certified increment over that analytic channel. Against protein-fixed synonymous resamples, the corresponding AUC values are `0.6619` and `0.6987`, with gaps of `+0.0931` and `+0.1296`. The Super context readouts clear the same comparisons. Grammar-trained models respond to biological sequence order under composition controls. Ranking sequences by compatibility with a criterion is standard in the field's benchmarks. Here the criterion is fixed by the grammar.

## Membrane topology in *E. coli*

The Topology domain covers 590 eligible *E. coli* K-12 integral membrane proteins with annotated transmembrane and cytoplasmic domains. For each gene, transmembrane windows are compared with cytoplasmic windows from the same coding sequence. The organism, gene, encoded protein, and host codon-usage table are shared. The annotated topological domain is the variable being tested.

The kernel statistic is the mean shell of adjacent codon pairs. The transmembrane-minus-cytoplasmic difference is `-0.2262` shell units. The contrast is negative in 492 of 590 genes, and the paired sign-flip permutation test gives `p = 0.0002`.

An amino-acid-preserving null redraws codons while keeping the encoded protein fixed. Its mean contrast is `-0.1825`, leaving an observed-minus-null residual of `-0.0436` with `p = 0.0002`. A usage-matched null samples synonymous codons using the host's observed codon frequencies. It reduces the residual to `-0.0234`, with 333 of 590 genes negative and `p = 0.0002`. The gated claim rests on the amino-acid-preserving residual. The usage-matched comparison is reported for the host-usage question.

Boundary composition was examined in two ways. Linear adjustment for codon-boundary dinucleotide content leaves an adjusted contrast of `-0.0387` with `p = 0.0002`. Exact preservation of every boundary dinucleotide leaves a residual of `-0.0011` with `p = 0.2064`. That second control pins junction composition as its own channel by fixing the bases where synonymous freedom normally sits. The near-zero residual confirms the Topology contrast lives in codon-identity order, the same design freedom the Synthesis domain scores.

Length matching pairs each transmembrane window with the closest cytoplasmic window from the same gene and keeps length differences within 10%. Across 1,854 pairs, the shell contrast is `-0.2105`, 70.3% of pairs are negative, and `p = 0.0005`. About 93% of the original contrast remains under this matching.

The estimand is association between adjacent codon-pair order and annotated membrane topology within genes.

## Frozen model reads on the topology cohort

Each Topology window also has frozen Narrow and Super readouts. Narrow heterogeneity has a mean transmembrane-minus-cytoplasmic difference of `-0.0214`. Super climate has a mean difference of `+0.0422`.

The held-out analysis uses 5,684 windows from 590 genes, including 4,059 transmembrane and 1,625 cytoplasmic windows. Genes are kept together in cross-validation folds so that windows from one gene stay on one side of the train-test split. AUC is a rank-based classification measure.

The baseline contains kernel shell, GC content, window length, and the model read-truncation flag. Its mean held-out AUC is `0.758432`. Adding Narrow heterogeneity and the model walk length raises AUC to `0.767527`. The incremental AUC is `+0.009094`, with standard deviation `0.000320` across ten grouped 10-fold seeds. All ten seeds are positive, and the paired two-sided permutation test gives `p = 0.0019`. For the 5,594 windows that remain within the frozen read length, the increment is `+0.009521`. The 90 longer windows are reported separately.

Narrow supplies the main unique contribution over the controlled baseline. Adding Super to Narrow gives `+0.009958`. Super alone gives `+0.000708`. K4 supplies the exact symmetry certificate and the splice-alignment floor.

A representation learned from grammar-generated sequence adds local order information beyond the fixed kernel geometry, GC content, length, and read policy.

## Fixed-peptide synonymous order

Gamble 2016 Table S1, measured in yeast, contains 35,811 nine-base variants across 5,148 encoded tripeptides. Within each tripeptide, the encoded protein and sequence length are fixed while codon order varies, and expression is measured for every variant in the `synGFPSEQ` expression column. This design isolates synonymous order while holding peptide composition fixed. Adjacent-codon effects on translation are documented in yeast [10, 11]. The question here is whether a grammar-trained measure detects them.

The eligible analysis set contains 28,504 variants in 2,597 peptide groups with at least five synonymous spellings. Frozen Super climate, Super context, Narrow heterogeneity, and kernel mean shell are scored before expression enters the analysis. GC content and codon-count entropy are reported as additional composition controls.

The primary readout is Super climate. Its mean within-peptide Spearman correlation with expression is `+0.0196` across the 2,562 groups that carry a defined within-group rank. The remaining 35 eligible groups have no rank variance and drop out. A total of 51.4% of groups are positive. The direction was pre-registered, since the gate requires a positive mean rank, so the one-sided sign-flip test is used, and it gives `p = 0.0038`. Peptide-held-out evaluation gives the same mean rank, `+0.0196`, and all five folds are positive. Kernel mean shell has a correlation of `+0.0066` on the same comparison. GC content is associated at `-0.0613`, so the Super climate rank tracks a channel distinct from GC. Super context norm, Narrow heterogeneity, and codon-count entropy remain near zero on this construction.

The estimand is a reproducible association between Super climate and expression under fixed peptide identity.

## Interpretation

The Genomics Program is one program with two domains. Synthesis delivers design capacity on living catalogs: exact symmetries, order memory, and climate discrimination under composition controls. Topology delivers biological readout capacity: membrane-topology climate inside individual genes, held-out classification lift from frozen Narrow, and synonymous expression ranking under fixed peptide identity.

Sequence order carries information across genomic structure, protein topology, and synonymous expression. Each analysis has its own controls and estimand.

The kernel supplies the grammar of the coordinate system. The learned measure ranks and locates sequences on that grammar for design scoring and topology readout. Narrow carries the held-out classification lift. Super carries the order-memory margin and the Gamble ranking. K4 carries the symmetry certificate. The Topology shell contrast is a property of the coordinate system and holds under protein, usage, boundary, and length controls. One frozen weight set serves both domains: regenerable from the null grammar by anyone with the repository, and used byte for byte without retraining.
